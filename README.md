## 📋 Функционал

### 👤 Для пользователя
- 📅 **Афиша мероприятий** – динамическая загрузка событий из JSON.
- 🪙 **Система монет** – получение наград за посещение событий.
- 📝 **Запись и отмена записи** – пользователь может записаться на ивент или отменить запись с возвратом монет.
- 📤 **Кнопка «Поделиться»** – автоматическая генерация поста для Telegram-канала со ссылкой на событие.
- 👤 **Профиль** – синхронизация имени и аватарки из Telegram.

### 🛠 Для администратора (Админ-панель)
- 🔐 **Авторизация через токен GitHub** – безопасный вход в панель управления.
- ➕ **CRUD для событий** – создание, редактирование и удаление мероприятий через интерфейс.
- 🖼️ **Загрузка изображений** – автоматическая загрузка картинок в репозиторий через GitHub API.
- 📦 **Управление JSON** – все изменения автоматически сохраняются в `events.json` без необходимости писать код.

## 🛠 Используемые технологии

| Технология | Назначение |
|------------|------------|
| **HTML5, CSS3** | Структура, визуальный дизайн, адаптивная верстка |
| **JavaScript (ES6+)** | Интерактивность, работа с DOM, API запросы |
| **GitHub Pages** | Бесплатный хостинг статического приложения |
| **GitHub REST API** | Сохранение данных (JSON) и загрузка картинок через админку |
| **localStorage** | Хранение данных о пользователе, монетах и купленных товарах |
